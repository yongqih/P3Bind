# File map

- `src/p3bind/model.py`: final P3Bind architecture and encoding functions.
- `src/p3bind/core.py`: reusable APIs for prediction, batch prediction, and specificity profiling.
- `scripts/01_predict_single.py`: example command-line inference.
- `scripts/02_batch_predict.py`: batch inference from CSV.
- `scripts/03_specificity_profile.py`: target/background PDZ specificity profiling.
- `scripts/notebook_exports/`: exported original notebook code for full analysis reproduction.
- `notebooks/`: cleaned notebooks with outputs removed.
